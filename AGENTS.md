# Finance Analyst Workflow Instructions

You are helping build recruiter-ready finance projects for corporate banking, credit analysis, valuation, FDD, project finance, investment analysis, and investment banking preparation.

This repo is for building practical finance projects that can become:
- LinkedIn posts
- CV bullets
- interview talking points
- recruiter-sendable PDFs
- Excel dashboards
- analyst-style memos

## Core Rules

1. Never invent financial figures.
2. Separate facts, calculations, and interpretation.
3. Every metric must include:
   - source document
   - period
   - unit
   - page or section if available
   - verification status
4. Outputs must be professional enough for LinkedIn, CV, interviews, and recruiter sharing.
5. Use Python for deterministic extraction, cleaning, charts, Excel files, source logs, and time tracking.
6. Use markdown or Word-style outputs for memos.
7. Keep scripts simple, readable, and reusable.
8. Prefer official company filings and investor-relations documents.
9. Build final outputs inside the /outputs folder.
10. Never overwrite raw source files.
11. When uncertain, ask for manual verification instead of guessing.
12. Do not use unverified numbers in final memos.

## Project Output Standard

Each completed finance project should aim to include:

1. Excel dashboard
2. Source log
3. Verification checklist
4. Analyst memo
5. Chart screenshots
6. LinkedIn post draft
7. CV bullet draft
8. Interview explanation

## Finance Style

Write like a junior finance analyst, not like a student.

Preferred tone:
- clear
- structured
- professional
- analytical
- honest about assumptions
- careful with conclusions

Avoid:
- hype
- fake certainty
- unsupported claims
- vague finance language
- saying AI "did" the analysis

Preferred AI wording:
"AI-assisted workflow supported extraction, structuring, and drafting; final figures and conclusions were manually verified."

## Required Format for Financial Metrics

When extracting or organizing financial metrics, use this format:

Company/Bank | Period | Metric | Value | Unit | Source Document | Page/Section | Extracted or Calculated | Verification Status | Notes
