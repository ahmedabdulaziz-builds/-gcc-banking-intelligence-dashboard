## Download Rules

1. Use official investor relations pages where possible.
2. Save PDFs into: data/raw/gcc_banking
3. Use clear file names:
   - FAB_FY2025_Annual_Report.pdf
   - FAB_Q1_2026_Results.pdf
   - ENBD_FY2025_Annual_Report.pdf
   - ENBD_Q1_2026_Results.pdf
   - QNB_FY2025_Annual_Report.pdf
   - QNB_Q1_2026_Results.pdf
   - ADCB_FY2025_Annual_Report.pdf
   - ADCB_Q1_2026_Results.pdf
4. Do not use unverified third-party numbers as final figures.
5. Every final KPI must be manually checked against the source.
