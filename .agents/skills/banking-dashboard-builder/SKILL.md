# Banking Dashboard Builder Skill

Goal:
Build a professional Excel dashboard comparing banks.

## Input

A verified KPI table with columns such as:

Bank | Period | Metric | Value | Unit | Source Document | Page/Section | Verification Status | Notes

## Required Excel Tabs

1. README
2. Raw Extraction
3. Verified KPI Table
4. Bank Comparison
5. Charts
6. Source Log
7. Analyst Notes
8. Time Saved Tracker

## Required Charts

Create charts where data is available for:

- ROE comparison
- ROA comparison
- Net interest margin comparison
- Cost-to-income ratio comparison
- NPL ratio comparison
- Coverage ratio comparison
- CET1 ratio comparison
- Loan growth vs deposit growth
- Profitability vs asset quality matrix

## Formatting Rules

- Use clean professional formatting.
- Freeze panes where useful.
- Make headers bold.
- Add filters to tables.
- Use consistent number formats.
- Do not hide formulas.
- Include source notes.
- Include verification status.
- Save final workbook to outputs/excel.

## Important Rules

- Do not create fake data.
- If data is missing, leave it blank or write "not found."
- Do not use unverified numbers in final charts unless clearly marked.
- Keep the workbook simple enough for a recruiter or interviewer to understand quickly.
