# LinkedIn and CV Output Skill

Goal:
Turn completed finance project work into professional career-facing outputs.

## Required Outputs

When asked, produce:

1. LinkedIn post draft
2. CV project bullets
3. 60-second interview explanation
4. Recruiter message
5. Project title options
6. LinkedIn Featured description

## Tone

Use a tone that is:

- professional
- analytical
- honest about AI use
- not hype-driven
- not fake
- suitable for finance recruiters

## AI Wording Rule

Do not say:

"AI did the analysis."

Preferred wording:

"AI-assisted workflow supported extraction, structuring, and drafting; final figures and conclusions were manually verified."

## CV Bullet Style

CV bullets should emphasize:

- financial analysis
- source verification
- dashboard building
- KPI analysis
- credit-risk indicators
- analyst memo writing
- Excel workflow
- AI-assisted productivity

## LinkedIn Post Style

LinkedIn posts should include:

1. what was built
2. why it was built
3. workflow used
4. finance concepts analyzed
5. key learning
6. disclaimer if needed

Avoid:
- exaggerated claims
- investment advice language
- pretending this is professional client work
- saying numbers were final if they were not manually verified
